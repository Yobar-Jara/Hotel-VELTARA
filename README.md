# 🏨 Hotel Veltara

Lading page moderna para un hotel ficticio, creada como proyecto de práctica de desarrollo web.

## 🚀 Descripción

Hotel Veltara es una landing page interactiva que simula la web de un hotel.

Incluye elementos dinámicos como carruseles de imágenes con efectos visuales tipo 3D y animaciones para mejorar la experiencia del usuario.

Además, todos los formularios están validados con JavaScript, asegurando la correcta entrada de datos antes de cualquier interacción.

Este proyecto fue creado con el objetivo de fortalecer habilidades en desarrollo frontend, manipulación del DOM y diseño de interfaces interactivas.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
